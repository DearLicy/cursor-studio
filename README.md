# Cursor Studio v1.0.0

Cursor Studio 是一款 Windows 桌面工具，用于集中管理个人 Cursor 使用体验。你可以在一个界面中管理模型供应商、用量、会话、提示词、MCP、Skills、外观和 Cursor 资料。

## 下载与使用

1. 打开 [Cursor Studio 发布页](https://github.com/DearLicy/cursor-studio/releases)。
2. 下载最新的 `CursorStudio-*-portable.exe`。
3. 将文件放到准备长期使用的文件夹中，双击即可启动。

便携版不需要安装向导。建议不要放在临时目录中，以便后续更新能够直接替换当前程序并自动重新启动。

## 功能一览

- **概览**：查看服务状态、缓存效率、近期用量和常用操作。
- **用量**：查看请求记录、Token 用量、预估费用、模型价格和供应商余额信息。
- **供应商**：添加和管理模型服务，测试连通性，选择模型，设置路由、余额或配额。
- **会话**：按最近记录或项目浏览 Cursor 会话，查看对话内容，快速定位消息，并清理空会话。
- **提示词**：整理和启用常用提示词。
- **MCP 与 Skills**：管理 Cursor 的 MCP 服务与已有 Skills，也支持导入技能仓库。
- **设置与外观**：调整代理、资料、背景外观和 Cursor 相关选项。

## 首次使用

1. 启动 Cursor Studio。
2. 打开 **供应商**，添加你正在使用的模型服务。
3. 在 **设置** 中完成需要的代理配置，并按照界面提示操作。
4. 回到 **概览**，点击启动服务。
5. 若 Cursor 已经打开，请完全退出后重新启动，再开始新的会话。

你可以随时在概览停止服务。停止后，程序会还原由自身管理的代理设置。

## 更新方式

Cursor Studio 会在启动时检查新版本，之后每六小时检查一次。每次检查也会刷新概览底部的推荐内容。

检测到新版本后，程序会显示版本号与更新说明。点击 **立即更新** 后，程序会下载更新包，在当前程序所在目录完成替换并重新启动。点击 **稍后再说** 只会关闭本次提示，不会下载或安装更新。

也可以在概览的社区与支持区域随时点击 **检查更新** 手动检查。

### 推荐内容

概览底部的推荐内容由 GitHub 仓库根目录的 `ads.json` 提供。程序启动、手动检查更新与每六小时的检查都会同步刷新；网络暂时不可用时会继续显示最近一次成功读取的内容。

## 数据与隐私

Cursor Studio 会在本机保存应用设置、用量摘要、备份和受管理的记录。供应商密钥保留在本机应用配置中。会话管理会读取 Cursor 的本地会话记录，以便在软件中统一浏览和清理。

检查更新时，程序会访问 Cursor Studio 的公开发布地址，获取版本信息和推荐内容。外部链接只会在你主动点击后打开。

在调整重要配置前，建议进入 **设置 > 备份与恢复** 创建备份。程序最多保留三份最近备份，也支持手动清理。

## 常见问题

### 服务没有启动

回到概览，点击 **启动服务**。如果 Cursor 已经打开，请先完全退出 Cursor，再在服务运行后重新启动它。

### 供应商测速失败

检查供应商地址、访问密钥、协议类型和网络连接，修正后再次点击测速。

### 为什么还没有用量数据

请求经过服务后才会生成用量记录。完成一次新的 Cursor 请求后，打开用量页面刷新即可查看。

### 为什么不会自动安装更新

更新始终由你确认。请将便携版程序放在有写入权限的目录中，检测到新版本后点击 **立即更新** 即可。

### 如何反馈问题

可在 **设置** 中导出支持信息，再通过社区联系方式发送问题描述和相关信息。
